# Task Tracker Project

## Goal
Build a simple task tracker app for ongoing work and progress updates.

The app should eventually allow:
- me to manage tasks
- TJ to access and edit tasks
- Google sign-in
- shared task data
- deployment to a live URL

## Core Task Fields
Each task should include:
- Task Name
- Project
- Week / Date
- Status
- Priority
- Due Date
- Work Done
- Validation
- Links
- Notes / Next Steps

## Status Options
- To Do
- In Progress
- Completed
- Pending

## Working Rules
- Inspect the project before making changes.
- Do not modify production systems.
- Keep the app simple and easy to understand.
- Test changes before committing.
- Never expose passwords, API keys, or secrets.
- Use environment variables for credentials.
- Build the basic tracker first before adding authentication.
- Ask for clarification if requirements are unclear.

## Build Order
1. Basic local task tracker
2. Add/edit/delete tasks
3. Filters and status dashboard
4. Shared database
5. Google authentication
6. User roles / TJ edit access
7. Deployment
8. Custom/shareable link
